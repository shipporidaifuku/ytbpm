# ytbpm

YouTubeの動画で楽曲のBPMを表示するFirefox拡張機能です。ボタンを押すと、音声からの実測とDeezerに登録されたBPMの検索を同時に行い、BPMとその2倍の値を表示します。

## インストール

Firefox 140以降が必要です。

### お試しで読み込む
1. Firefoxで `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む…」を押し、このリポジトリの `manifest.json` を選ぶ

一時的なアドオンはFirefoxを再起動すると消えます

## 使い方

YouTubeの動画を開くと右下にボタンが出ます

### ネット情報
- deezerにBPMが登録されていない曲は「見つかりませんでした」になります。その場合は表示されるリンクからWeb検索できます
- 見つかった曲名とアーティストを表示します。アーティストが一致しないときは「同名の別の曲かも」と警告が出ます
- 「アーティスト - 曲名」や「アーティスト「曲名」」の形のタイトルは読み取りやすく、それ以外はチャンネル名をアーティストとして扱います

### 実測
- 動画の再生中だけ測定が進むようになってます
- ミュート中は音が取れないので測定できません

## 開発

Node.js 22以降が必要です。

```bash
npm install
```

| コマンド | 内容 |
|---|---|
| `npm test` | テストを実行 |
| `npm run lint` | AMOと同じ検査（web-ext lint）を実行 |
| `npm run build` | 提出用のzipを `web-ext-artifacts/` に作成 |
| `npm start` | 拡張機能を読み込んだFirefoxを起動 |

## プライバシー

動画のタイトルとチャンネル名をDeezerに送信します。詳しくは [PRIVACY.md](PRIVACY.md) を見てください。
